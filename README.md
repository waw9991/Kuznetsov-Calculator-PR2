## Открытие в Visual Studio

Нужны Windows и Visual Studio 2022 версии 17.8 или новее с компонентом «Разработка классических приложений .NET» и средствами .NET 8.
Проверено в Visual Studio Community 2026 18.4.2, .NET SDK 10.0.201; целевая платформа проектов — .NET 8.

1. Открыть `KuznetsovCalculator.sln`.
2. Дождаться восстановления пакетов NuGet; для первого восстановления нужен интернет.
3. Назначить `KuznetsovCalculator.Wpf` запускаемым проектом.
4. Выполнить сборку и запуск F5 или Ctrl+F5.
5. Выбрать **Тест → Запуск всех тестов**.

## Проверка из терминала

```powershell
dotnet restore KuznetsovCalculator.sln
dotnet build KuznetsovCalculator.sln -c Release
dotnet test KuznetsovCalculator.sln -c Release
dotnet run --project KuznetsovCalculator.Wpf -c Release
```

Проверено 24.10.2026: **51 из 51 тестов пройдены**, пропущенных нет; сборка без ошибок и предупреждений.

Операции: `+`, `-`, `*`, `/`, `^`. Дроби принимаются с точкой и запятой.
Поддерживаются вложенные скобки, унарный минус, степени справа налево и история 20 расчётов.
`Enter` или `=` вычисляет, `Esc` очищает ввод. После результата цифра начинает новое выражение, оператор продолжает расчёт.
Ошибки выводятся в окне; ошибочные выражения в историю не попадают.

| Проект | Назначение |
| --- | --- |
| KuznetsovCalculator.Core | Арифметика и разбор выражений |
| KuznetsovCalculator.Wpf | Окно, ввод, история и модель представления |
| KuznetsovCalculator.Tests | 12 проверок операций, 28 выражений и 11 модели представления |

Контрольные результаты: `8+2*5 = 18`, `(8+2)*5 = 50`, `2^3^2 = 512`, `-3^2 = -9`, `2^-3 = 0,125`.
